* Access And Product Boundaries

Use SSH for administration and tunnel RDP to the guest's port 3389. Keep the
guest RDP firewall port closed; bind host-side forwards to loopback. Example
after an installed guest is reachable:

#+begin_src sh
ssh -N -L 127.0.0.1:13389:127.0.0.1:3389 nixos@<vm-host>
#+end_src

An RDP client connects to =127.0.0.1:13389=. Adapt SSH addressing for the
actual provider. RDP starts its own session without a prior console login;
console-session mirroring is not required. VM console access remains useful
for boot/recovery and is operator-owned.

Public fixture credentials: live ISO users =nixos= and =root= use password
=nixos=; the installed minimal user is =nixos= with password =nixos=, sudo
uses that user's password, and installed root is locked. Preserve this policy
for the new example. =--no-root-password= suppresses the installer prompt;
it does not enable passwordless root login. The example assumes BIOS/GRUB
and =/dev/vda=; observe the disposable target disk before invoking the helper.

The builder already embeds all of =examples/= by default. A supplied
=CONFIG_DIR= replaces that tree. Keep the live installer itself headless.
GUI app/toolchain provisioning, GPU-performance certification, audio,
clipboard/drive sharing, Wayland, and a full desktop suite are outside this
epic's acceptance requirements.
